**W♡W — Landing Page**

Landing page oficial do W♡W, um aplicativo de relacionamento criado para mulheres que amam mulheres.

**Conexões reais. Encontros leves. Um espaço feito para mulheres que amam mulheres. 💗**

O projeto apresenta a proposta do aplicativo, seus recursos, princípios de segurança e a experiência que estamos construindo para criar conexões mais leves, reais e respeitosas.

✨ Sobre o projeto

O W♡W nasceu com a ideia de criar um espaço pensado especificamente para mulheres que buscam conhecer outras mulheres.
